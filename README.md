# kalshi-research — experiment 008

**Are Kalshi contract prices calibrated?** That is, do contracts trading at price `p`
resolve YES with frequency `p`?

This repository contains a **measurement study**. It produces **no trading rule and no
strategy**. `PREREG_008.md` §8 forbids designing one from these results without a new
pre-registration that states which category was selected and why.

## Running it

```bash
pytest -q                                          # 53 tests
python scripts/run_calibration.py --fees           # step 0: the verified fee schedule
python scripts/run_calibration.py --ingest         # steps 1-3: data, join, snapshots
python scripts/run_calibration.py --gates          # steps 2-4: run every gate
python scripts/run_calibration.py --permutation-null   # step 8: both null tests
python scripts/run_calibration.py --full           # everything + FINDINGS_008.md
```

`--ingest` is the long pole. It paces itself to **4 requests/second** against Kalshi's
free public API — a rate measured safe on 2026-08-21 (60/60 HTTP 200 at 4 req/s; 19/60
HTTP 429 at 8 req/s). Every response is cached in `data/cache/http_cache.sqlite`, so the
run is resumable and re-running the analysis costs no requests.

Add `--offline` to run purely from cache.

## Data sources

Kalshi's public, unauthenticated API only. No aggregator, mirror or scraped source was
used at any point; if the API is unreachable the pipeline stops and says so rather than
substituting anything.

- `GET /series` — all 13,339 series with category, `fee_type`, `fee_multiplier`
- `GET /historical/markets?mve_filter=exclude` — the archive tier, back to 2021-08
- `GET /markets?status=settled&mve_filter=exclude&min_close_ts&max_close_ts` — the live tier
- `GET /historical/markets/{ticker}/candlesticks` — archive prices
- `GET /series/{s}/markets/{ticker}/candlesticks` — live prices
- `GET /historical/cutoff` — the moving boundary between the two tiers

The two candlestick endpoints return **different field names for identical data**
(`price.close_dollars` vs `price.close`, `volume_fp` vs `volume`) and differ in how they
represent a no-trade period. `ingest.normalise_candle()` folds both into one shape.
